# Honest boundaries

1. **Synthetic and independent.** Fictional organization, products, users, records and operations. No actual manufacturer's systems, processes, integrations, endorsement, deployment, confidential information, measured customer benefit or compliance certification is represented.
2. **Local demo, not production service.** Standard-library HTTP on loopback, SQLite files, no authenticated identities, SSO, TLS termination, managed backup service, monitoring, deployment automation or multi-tenant isolation. The demo selector does not prove who is acting.
3. **Focused correction path.** Reviewed recovery of BUF-1042 is complete. Other seeded defects remain inspectable and quarantined. Arbitrary raw-row replacement/supersession, master-data editing and generalized correction approvals are not implemented. Admin imports add evidence; they do not erase old defects.
4. **Simplified operational model.** One order per work cell per shift, fixed synthetic SKU targets, a four-step route, three stations, one sampled check per order. No machine capacity, maintenance, staffing, unit-level genealogy, inventory, material consumption, product release or regulatory electronic signatures.
5. **Time semantics.** UTC event/shift semantics avoid silently misinterpreting offsets. No local-time/DST roster editor. Freshness is source-transfer latency against a fixed scenario clock, not live source-health monitoring. Audit records use actual UTC action time.
6. **Cohort reporting.** Charts group by order start date and station, not shipment calendar or labor-normalized productivity. Counts are completed units, not guaranteed good units. Sample checks are not yield. No OEE or ROI claims.
7. **Detector evaluation.** The original designed seed and six-condition / five-seed stress protocol cannot estimate real-world accuracy. Stress conditions show both false alerts and misses; zero-MAD scoring is deliberately brittle and low-sample baselines abstain. They stress the detector on a representative single-station distribution, not a full factory simulation. Chronological train/test separation is tested, but does not establish causal inference or external validity. No model registry or deployed drift monitoring.
8. **Audit integrity.** App workflows append audit and prohibit raw/audit updates; filesystem administrators can still alter SQLite. Hashes are source fingerprints, not cryptographic attestations. Explicit scenario reset clears production/review state but retains audit and feedback; historical linked-incident audit includes earlier reset runs.
9. **Error scope.** JSON import supports 1–5,000 events, at most 2 MB over HTTP. Structural invalidity or row-identity collision rejects the batch; rejected files are not copied into a permanent dead-letter store. Domain-invalid staged rows are retained and surfaced.
10. **Verification boundary.** The original 91 backend/domain/HTTP tests and 42 JavaScript rendering/interaction tests are supplemented by 11 publication tests. Exact executed results are recorded in [ACCEPTANCE.md](../ACCEPTANCE.md). JavaScript tests use a Node VM, not a real browser DOM. Seven supplied application captures were inspected on 17 November 2026; the separately labeled comparison graphic is editorial. These static images do not verify the full browser journey, target viewports, keyboard-only flow or file dialogs. Final recording sign-off remains outstanding.
11. **Accessibility.** Semantic controls, labels, visible focus, skip link, textual states, reduced-motion handling and tabular chart values are included. No formal WCAG audit, assistive-technology certification or broad cross-browser/device test was performed.
12. **Scope of the delivery.** Code, documentation, test evidence and a ready-to-rehearse recording script are delivered. No video recording, deployment, publication, outreach email or company contact was performed. Windows/Python 3.12.0 is locally verified; other configured CI environments await hosted execution.
13. **Human disposition.** Closure validates role, state, structured justification, confirmation and reference ownership; it cannot verify the truth of free text or a mitigation's actual efficacy. Causal uncertainty is retained. Work plans are recorded intentions, not verified completed actions.
